### 새로 넣은 기능
1. **생활어 검색** — 기관 이름을 몰라도 됩니다. 기관 51곳 모두에 `당근 사기`, `먹튀`, `월급 안 줌`, `퇴직금`, `층간소음`, `스미싱`, `보이스피싱`, `불법주차`, `악플`, `택배`, `딥페이크` 같은 생활어를 붙였습니다(키워드 468개). 띄어쓰기·가운뎃점을 무시하고 찾습니다.
2. **"이럴 땐 여기!" 구분 안내** — 헷갈리는 기관을 카드와 상세 창에 나란히 보여줍니다. 예: 중고거래 사기 → 경찰 ECRM / 쇼핑몰 환불 거부 → 소비자원 1372 / 단순 스팸 문자 → 118 / 링크 눌러 돈이 빠져나감 → 112 + 1332 지급정지.
3. **방법 배지 + 준비물 체크리스트** — 카드에 `24시간`, `온라인 접수`, `전용 앱`, `전화 상담` 배지를 달고, "신고 전 준비물"을 펼쳐 볼 수 있게 했습니다(이체확인증, 대화 캡처, 녹취 등).
4. **긴급 SOS 바** — 헤더 아래 한 줄: 보이스피싱(112·1332), 사이버사기(ECRM), 해킹·개인정보(118), 학교폭력(117).
5. **안전망** — 검색 결과가 0건이거나 `어디인지 모르겠어요`를 누르면 국민신문고, 국민콜110, 지자체 민원(지역번호+120)을 안내합니다.
6. **신고 내용 정리 도우미** — 일시·장소·상대방·피해 내용을 적으면 6하원칙 형태 문장으로 만들어 클립보드에 복사합니다. **서버로 전송되지 않고** 브라우저(localStorage)에만 남습니다.
7. **깨진 링크·기관 추가 제안** — 푸터에서 GitHub 이슈 또는 이메일로 보낼 수 있습니다.

### 데이터가 두 곳에 있는 이유
GitHub Pages에서는 `fetch('data.json')`으로 읽습니다. 그런데 파일을 더블클릭해 열면(`file://`) 브라우저가 fetch를 막기 때문에, `index.html` 안에 같은 데이터를 넣어 두고 실패하면 그쪽을 씁니다. **둘을 손으로 고치지 말고 `data.json`만 고친 뒤 아래 명령으로 다시 만드세요.**

```bash
cd singo
python3 _build/build.py     # index.html 재생성
```

5. 문제가 있으면 예전 `index.html`만 되돌리면 됩니다(이전 파일은 `projects/singo/_original/`에 보관).

## 데이터 고치기

`data.json`의 `items` 배열에 한 건을 추가하는 예:

```json
{
  "id": "my-agency",
  "menu": "신고/민원",
  "main": "생활불편 신고",
  "sub": "도로·시설",
  "org": "기관명",
  "name": "서비스 이름",
  "desc": "카드에 보일 한 줄 설명",
  "phone": "1234",
  "url": "https://example.go.kr",
  "tags": ["태그"],
  "type": "정부",
  "stype": "신고",
  "methods": ["24시간", "온라인 접수", "전화 상담"],
  "keywords": ["생활어", "사람들이 검색할 말"],
  "checklist": ["준비물1", "준비물2"],
  "tip": "헷갈릴 때 안내 문장",
  "compare": [{ "case": "이런 상황", "go": "저 기관" }]
}
```

- `menu`는 `menus`에 있는 값이어야 하고, `main`도 그 메뉴의 `key` 중 하나여야 합니다. `sub`는 자유롭게 새로 만들어도 됩니다.
- `phone`이 `-`이면 전화 버튼이 나오지 않습니다. `1544-8080`처럼 하이픈이 있어도 `tel:` 링크는 숫자만 씁니다.
- `methods`는 `24시간`, `온라인 접수`, `전용 앱`, `전화 상담`, `문자 상담`, `채팅 상담`, `방문 접수`, `방문 진단`, `온라인 조회`, `온라인 발급`, `온라인 상담` 중에서 쓰면 배지 색이 맞춰집니다.
- `compare`는 카드와 상세 창의 "이럴 땐 여기!" 표에 들어갑니다.
- 고친 뒤 `python3 _build/build.py`를 실행해야 `index.html`에 반영됩니다.
